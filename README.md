# Computer Security · Module 1 · Master's ODL Forum

Discussion forum for **Module 1: Computer Security Overview** (master's cohort, open and distance learning).
All work happens in the **Discussions** tab of this repository: one thread per activity.

> ⚠️ This repository is **public**. Anyone on the internet can read the discussions.
> When you draw on your own workplace, **anonymise it**: no organisation names, system names, IP addresses or staff names.

## How to take part
1. Sign in to GitHub (create a free account if you do not have one).
2. Open the **Discussions** tab and find the thread for the current activity.
3. Click **Write** in the comment box, copy the reply template from the thread, and fill it in.
4. Reply to classmates in their comment threads. Use 👍 to upvote strong answers.

## Marking rubric (16 marks per task)
| Criterion | Excellent (4) | Good (3) | Developing (2) | Weak (1) |
|---|---|---|---|---|
| Use of concepts | Precise Module 1 terms, applied correctly | Mostly correct terms | Some terms misused | Terms missing or wrong |
| Critical analysis | Weighs trade-offs and justifies choices | Some justification | Mostly descriptive | Descriptive only |
| Evidence | Cites standards or credible sources | Cites one source | Vague reference | No sources |
| Peer engagement | Challenges peers with reasons or counter-examples | Adds a relevant point | Agrees with little detail | No reply |
